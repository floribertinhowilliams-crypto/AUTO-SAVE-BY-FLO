# AutoSave Contacts Pro

Phase 02 Android project foundation.

## Open in Android Studio
1. Extract this ZIP.
2. Open Android Studio.
3. Choose Open.
4. Select the extracted `AutoSaveContactsPro` folder.
5. Let Gradle sync.
6. Build > Build APK(s).

Phase 03 has NOT been implemented. Notification parsing and automatic phonebook saving are intentionally placeholders.
